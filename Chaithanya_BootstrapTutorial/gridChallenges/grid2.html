Grid Specification #02

Grid Challenge 2: Responsive Stacking

4-2-6 column split on large displays collapsing to full 12-column width with vertical row-gap spacing on medium and smaller screens.

Professor's Exact Specification

Active Breakpoint: XS (<576px) SM (≥576px) MD (≥768px) LG (≥992px) XL+ (≥1200px)
  • At the lg container size (≥992px): Column 1 spans col-lg-4, Column 2 spans col-lg-2, Column 3 spans col-lg-6.
  • For the md breakpoint and below (≤768px): All columns span col-12 (12 columns full width).
  • Row-gap applied: Uses Bootstrap gutter gy-3 / row-gap for clean vertical separation when stacked.
  • Each column features a distinct color, py-3 vertical padding, and a column identifier.
